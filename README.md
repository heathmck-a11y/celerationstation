# Celeration Station

A Precision Teaching app for K–2 letter sounds and slides. It runs in the browser with no login.

- Named letter sets and slide sets (consonant + short vowel)
- Timed probes, either on a full page or one item at a time, with error marks hidden while the timer runs
- Daily Standard Celeration Chart with phase change lines and celeration lines
- Decision rules after each timing, including retention checks
- Today page with every student's next step
- Practice sprints, which are not charted
- Printable paper probes sized by grade, each with a teacher scoring copy
- Chart PDF, CSV export, and backup files

Results are saved in the browser on the device where the app is used. Use the Backup page to download a backup file now and then.

To publish with GitHub Pages, go to Settings, then Pages. Under Branch, choose `main`, then `/ (root)`, and save.
